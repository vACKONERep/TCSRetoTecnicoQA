# Demoblaze Automation Challenge

Reto técnico de automatización de pruebas para proceso de selección.

## Contenido

- **E2E UI**: Automatización del flujo de compra con Serenity BDD + Screenplay
- **API**: Pruebas de Signup y Login con Karate

## Tecnologías

- Java 17
- Serenity BDD + Screenplay
- Cucumber
- Karate
- Maven
